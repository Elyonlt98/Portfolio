# Lakshya Tiwari — portfolio

Personal site for Lakshya Tiwari, mechanical engineer and PhD researcher at UT Dallas working on laser-assisted joining of silicon carbide ceramics.

Live at https://elyonlt98.github.io/Portfolio/

## Structure
- `index.html` — single-page site
- `index.css` — styles (self-hosted Archivo and Source Serif 4, see `fonts/` for licenses)
- `index.js` — footer year and back-to-top button
- `img/` — optimized images, schematics (`fig-setup.svg`), favicon and share preview (`og.jpg`)

No build step: edit the files and push to `main`; GitHub Pages serves them as-is.
